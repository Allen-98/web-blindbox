# 水中捞月 × 中秋盲盒

版本：**0.2.0**。适配手机、平板和电脑的静态网页小游戏。

[在线游玩](https://www.zhaocai7.cn/games/blindbox/)

## 玩法

- 一局捞月限时 60 秒，捞齐 3 个月亮获得 1 张盲盒券，初始 0 券。
- 摇摆抓钩打捞月亮；岩石、碎片、小鱼形成干扰，部分月亮随小鱼移动。
- 每局可以松钩 1 次，提供水纹、光点、提示与可关闭的音效。
- 1 张券兑换 1 小局盲盒，4 行 3 列共 12 盒；凑齐三个相同图案结束。
- 玉兔 50 分、桂枝 30 分、月饼 10 分；包含个人成绩和基础收藏图鉴。
- 积分商店：100 可用积分兑换 1 张盲盒券，累计积分不因消费减少。旧存档已有总分自动成为初始可用余额。兑换前确认，保留最近 5 次兑换展示。
- 使用浏览器本地存档，兼容整合版历史存档。不同域名、浏览器或设备之间不自动同步。

## 本地运行

使用任意静态 HTTP 服务器打开仓库目录，例如已安装 Python 时运行：

```sh
python -m http.server 5173
```

然后访问 http://localhost:5173/ 。不要直接双击 HTML，游戏贴图加载需要 HTTP 服务。

## 测试

安装 Node.js 后运行 `npm test`。不需要安装 npm 依赖。测试覆盖存档迁移、12 盒规则、松钩、奖励、成绩、收藏、商店兑换与重复扣款等核心逻辑。浏览器测试使用 Playwright：先 npm install，再 npm run test:browser（默认使用本机 Chrome，可通过 CHROME_PATH 指定路径）。

## 部署

将运行文件复制到静态网站目录即可，入口为 `index.html`。IIS 使用附带的 `web.config` 支持默认文档和 WebP。现有线上路径为 `/games/blindbox/`。更新前备份旧文件；不要将密钥、服务器连接配置和备份文件放入公开目录。

## 文件

- `app.js`：画面和交互；`game-engine.js`：捞月模拟。
- `wallet.js`：盲盒券、得分、成绩、收藏及存档事务。
- `legacy-engine.js`：盲盒三同规则；`feedback.js`：视觉/音效反馈支持。
- `assets/`：游戏素材；`vendor/`：本地 Phaser 运行库和许可证。
- `docs/素材说明.md`、`THIRD-PARTY-NOTICES.md`：素材与第三方说明。
