# 本地素材说明

所有运行图像都随包放在 assets 目录，页面不加载网络图像。画风统一为深蓝湖夜、暖金月光、桂花与蓝金玉兔。

| 图像 | 原始 PNG | 运行 WebP | 用途 |
|---|---|---|---|
| rabbit-boat | 1942×809，透明 | 1000×417，121948 字节 | 顶部玉兔木舟与绞盘，以 240×100.08 逻辑像素等比例呈现；挂钩原点对齐中央偏右绞盘，待机钩位于船下方且全摆幅可见 |
| moon | 1254×1254，透明 | 160×160，10086 字节 | 三颗金色满月目标，以及携月鱼的月亮 |
| fish | 1254×1254，透明 | 160×160，8832 字节 | 面向右的小鱼，向左游时镜像；携月鱼叠加月亮与小星光 |
| rock | 1254×1254，透明 | 160×160，6520 字节 | 较重固定河石；缩小旋转后作为碎片 |
| moon-scene | 1024×1536 | 900×1350，216458 字节 | 首页背景与湖面画风底图 |

四张新图均由内置图像生成工具创建，原 PNG 已检查真正透明像素。WebP 通过 Sharp 做常规等比例缩小和格式优化，保留透明通道，不改变画面内容和色调。七张运行 WebP 合计 573186 字节；原 PNG 保留在工作目录作为来源，正式部署包只含运行 WebP。

## 提示词要点

- 船：白色玉兔蓝金古服与桂花饰，侧视中国木舟中央偏右绞盘两灯笼，无绳无背景。
- 月：完整金色满月环边/月坑，透明孤立。
- 鱼：面向右的青玉金鳍圆润小鱼，透明孤立。
- 石：圆润蓝灰河石，海蓝反光，透明孤立。

旧 moon-scene、blindbox-hero、prize-items 来自本工作目录既有本地图，延续原盲盒视觉。生产素材清单见 runtime-manifest.json。
